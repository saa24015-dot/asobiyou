📖 ぼうけんの手引き（Firebase Hosting デプロイガイド）

この単一HTMLファイルアプリを自前のFirebase Hosting環境へデプロイし、Google Authやリアルタイム世界ランキングを本格稼働させる手順です。

ステップ1: Firebaseコンソールの準備

  1. Firebase Console にアクセスし新規プロジェクトを作成。
  2. 「Authentication」を選択し、ログインプロバイダで「Google」を有効化。
  3. 「Firestore Database」を作成し、テストモードまたは本番モードで開始。

ステップ2: Firestore セキュリティルール設定

Firestoreの「ルール」タブに以下を設定して公開してください：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if true;
    }
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

ステップ3: ローカル＆GitHubからのデプロイコマンド

# Firebase CLIのインストール
npm install -g firebase-tools

# ログインと初期化
firebase login
firebase init hosting

# ビルドフォルダに index.html を配置しデプロイ
firebase deploy --only hosting
